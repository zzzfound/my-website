# my-website

一个简单、干净的个人主页，纯 **HTML / CSS / JavaScript** 搭建，无任何第三方依赖。

## 功能

- 响应式布局（手机 / 桌面自适应）
- 深色 / 浅色主题切换（记忆偏好）
- 实时时钟

## 本地运行

直接用浏览器打开 `index.html` 即可，无需安装任何东西。

```bash
# 或者用任意静态服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 文件结构

```
my-website/
├── index.html   # 页面结构
├── style.css    # 样式（含主题变量）
├── script.js    # 交互逻辑
└── README.md
```
